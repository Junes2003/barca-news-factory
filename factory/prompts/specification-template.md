# Task specification template

## Goal
What should change?

## Motivation
Why is the change useful?

## Scope
What should be built? Include relevant files or components and exclusions.

## Dependencies and constraints
Prerequisite issue numbers, security constraints, technology constraints and assumptions.

## Acceptance criteria
- Observable, individually checkable outcomes.
- Include relevant edge cases and expected behavior.

## Verification
Commands or manual steps to verify acceptance criteria. Identify tests that need adding.

## Open questions
Questions that require the owner's decision. Use "None" when there are no material questions.
